🍔 DevBurguer - Sistema de Gestão de Vendas Full Stack
Este projeto faz parte do meu portfólio de Desenvolvedor Full Stack  e consiste em uma aplicação completa para gerenciamento de pedidos de uma hamburgueria, focando em escalabilidade e experiência do usuário (UX).
+1

🚀 Tecnologias Utilizadas
O projeto foi construído utilizando tecnologias modernas de mercado para garantir performance e manutenibilidade:

Front-end: React.js com Vite para um desenvolvimento ágil e otimizado.


Gestão de Estado: Redux para controle de fluxos complexos de carrinho e autenticação.


Back-end: Node.js para criação de APIs robustas.
+1


Banco de Dados: Integração híbrida com SQL e MongoDB para diferentes necessidades de persistência.


Infraestrutura: Docker para conteinerização, facilitando o deploy e a consistência do ambiente.

Padronização: Configuração rigorosa de ESLint e Prettier para garantir a qualidade e limpeza do código.

🛠️ Funcionalidades Principais

Interface Responsiva: Adaptada para dispositivos móveis e desktop.


Fluxo de Compras: Seleção de produtos, adição ao carrinho e checkout simulado.

Documentação e Organização: Uso de arquivos .gitignore e ferramentas de versionamento para boas práticas de desenvolvimento colaborativo.

📦 Como Executar o Projeto
Clone o repositório:

Bash
git clone https://github.com/cassiano022/seu-repositorio.git
Instale as dependências:

Bash
yarn install
# ou

Inicie o ambiente de desenvolvimento:

Bash
